# README

This is an example project to try and familiarise myself with golang.

It's going to contain errors, bad ways of doing things, and things that I expect I'll look back on and be ashamed of.

It's also going to show my learning, and allow me to see the mistakes I've made.

Hopefully it'll prove some use for someone else.

## Aim

I often do my dog walks around Wanstead Flats, and have stopped on a regular basis and taken a photo at the same spot.

I have an Android Phone, and all these photos are backed up to Google Photos.

I'd like this app to:

1) Authenticate as me to Google, so that I can access photos.
2) Allow me to set a long/lat to find all photos taken at a particular point.
3) Identify a photo tha looks like the one that others will be similar to.
4) Find all the other photos that are very similar.
5) Stitch them together (oldest first) into a sequence of images.
6) Cache the data, so that next time I run the command, it just looks for new images that I may have taken since the last run.

I can probably acheive all of this already using languages/commands I already know; but here's a challenge!
